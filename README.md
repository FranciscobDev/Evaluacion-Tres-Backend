# Evaluacion-Tres-Backend
Es la evaluación tres haremos una pagina de gestión de citas para una clinica dental llamada CheckDent con Python/Django

Nombre de la Organización o Plataforma: CheckDent
Modelo de Negocio / Giro: Centro de atención Dental
Integrantes del Equipo: Francisco josue Briones Contreras , Mauricio Agustin Manterola Lopez
Entidad de Contexto / Agrupación (ORM): EspecialidadMedica
Entidad Principal Gestionable (ORM): PrestacionMedica
Propósito de la Sesión (request.session): implementar el Cotizador



Uso de Inteligencia Artificial en el desarrollo

Organización de los datos: Se usó IA para diseñar cómo se guardan de forma segura las especialidades y los tratamientos en la base de datos

Seguridad y permisos: Se le pidió ayuda a la IA para crear los "candados" del sistema, garantizando que un dentista no pueda entrar a las configuraciones del administrador, y que cada trabajador solo vea las pantallas que le corresponden a su cargo.

Sistema de presupuestos: Se diseñó una función para que la clínica pueda armar cotizaciones o presupuestos dentales en tiempo real.
